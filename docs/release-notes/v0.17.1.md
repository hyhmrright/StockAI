## StockAI v0.17.1

> 一个重要修复：分析历史、大师命中率和你的持仓，从这一版起才真正保存下来。

### 🐛 修复 / Bug Fixes

- **分析历史、大师命中率、我的持仓此前在安装版里从未保存**：应用缺少写入本地数据库的权限，每次保存都被系统拒绝，其中历史与命中率的保存失败在界面上毫无提示。表现为：历史记录列表始终为空、虚拟大师组合的命中率榜与净值曲线没有数据、添加持仓时报错且无法保存。现已修复，并加了自动检查，防止同类问题再次出现。**此前的分析记录无法找回**（它们从未写入磁盘），升级后新的分析会正常保存；持仓请重新添加。
- **新闻搜索不再编造「XXX 相关新闻 1」这类占位条目**：当 Google 新闻搜索没有结果时，此前会把页面上的零星外链当作新闻，配上自动生成的标题返回。这会让一个根本不存在的股票代码也「找到」新闻，绕过「查无此股」的提示。现在只收录带真实标题、且与该标的相关的结果。

### ⚡ 性能 & 体验 / Performance & UX

- 底层框架升级至 Tauri 2.12，通知、数据库、更新等 7 个系统插件同步升级；AI SDK（OpenAI / Anthropic）升至最新版。
- 修复构建工具链中一处高危安全公告（source-map-js，仅影响构建过程，不进入安装包）。

### 📦 安装 / Installation

**macOS**（当前构建矩阵仅出 Apple Silicon，无 Intel x64 dmg）
1. 下载 `StockAI_0.17.1_aarch64.dmg`（Apple Silicon）
2. 打开 DMG，将 StockAI 拖入 Applications
3. 首次启动若提示「无法验证开发者」：系统设置 → 隐私与安全性 → 仍要打开

**Windows**
1. 下载 `StockAI_0.17.1_x64-setup.exe`，双击安装，按向导操作即可

**Linux**
1. 下载 `StockAI_0.17.1_amd64.deb`
2. `sudo dpkg -i StockAI_0.17.1_amd64.deb`

**首次配置**
打开应用 → 右上角设置 → 填入 AI 提供商（OpenAI / DeepSeek / GLM / Anthropic / Ollama）的 API Key → 保存，即可开始使用。

> 已安装 v0.15.0 及以上版本的用户会收到应用内更新提示，无需手动下载。

## StockAI v0.17.1

> One important fix: your analysis history, master hit rates and holdings are actually saved starting with this release.

### 🐛 Bug Fixes

- **Analysis history, master hit rates and your holdings were never saved in the installed app**: the app lacked permission to write to its local database, so every save was rejected — and for history and hit rates, without any visible error. Symptoms: an always-empty history list, no data in the virtual master portfolio's hit-rate leaderboard and equity curve, and an error when adding a holding, which then failed to save. This is now fixed, with an automated check to keep it from coming back. **Earlier analyses cannot be recovered** (they were never written to disk); new analyses are saved normally after upgrading — please re-add your holdings.
- **News search no longer invents placeholder items like "XXX 相关新闻 1"**: when Google News search had no results, stray links on the page were returned as news with auto-generated titles. A stock code that doesn't exist could therefore "find" news and bypass the "stock not found" message. Only results with a real title that are relevant to the ticker are kept now.

### ⚡ Performance & UX

- Upgraded to Tauri 2.12, along with 7 system plugins (notifications, database, updater and more); AI SDKs (OpenAI / Anthropic) updated to their latest versions.
- Resolved a high-severity advisory in the build toolchain (source-map-js; affects the build process only, not the installed app).

### 📦 Installation

**macOS** (current build matrix ships Apple Silicon only — no Intel x64 dmg)
1. Download `StockAI_0.17.1_aarch64.dmg` (Apple Silicon)
2. Open the DMG and drag StockAI into Applications
3. If macOS says "cannot verify developer": System Settings → Privacy & Security → Open Anyway

**Windows**
1. Download `StockAI_0.17.1_x64-setup.exe` and run the installer

**Linux**
1. Download `StockAI_0.17.1_amd64.deb`
2. `sudo dpkg -i StockAI_0.17.1_amd64.deb`

**First-time setup**
Open the app → Settings (top-right) → enter your AI provider API Key (OpenAI / DeepSeek / GLM / Anthropic / Ollama) → Save. Done.

> Users on v0.15.0 or later will be prompted to update inside the app — no manual download needed.
