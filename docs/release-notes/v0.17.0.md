## StockAI v0.17.0

> 三位看市场行为的大师开始读资金流，港股新闻恢复，设置页布局修好——报障时也终于有日志可附了。

### ✨ 新特性 / New Features

- **德鲁肯米勒、伯里、伍德开始参考主力资金流**：资金流数据早就在界面上展示，但 13 位大师一个都没读。现在接给了本就看重「市场行为」的三位——斯坦利·德鲁肯米勒判断动能有没有真金白银撑着，迈克尔·伯里看是谁在抛售、是否构成错误定价，凯西·伍德看市场是否开始为创新叙事买单。其余 10 位价值派刻意不接：对看多年财报的人来说，每日资金进出只是噪声。这也让大师共识更可信——此前 13 位读的是同一份数据、分歧只来自措辞，「10/13 看涨」其实被严重高估了。主力资金方向一翻转，深度分析就不会再复用这三位的缓存结论，不会拿净流入时的判断顶净流出的现状。
- **遇到问题可以一键附上诊断日志**：设置 → 常规设置 → 诊断日志 →「打开目录」，报障时附上里面的 `sidecar.log`，定位会快很多。此前安装版应用的诊断信息几乎全被丢弃，留下来的 90% 是每 10 秒一次的报价轮询记录。现在数据源回退、抓取失败这类关键线索都会写下来；日志存在系统的应用日志目录里，不会被应用更新抹掉，单文件 512 KB 自动轮转不会越积越大，写入前自动抹掉 API key 等敏感信息，可以放心贴进 issue。

### 🐛 修复 / Bug Fixes

- **港股新闻的两个快速源此前实际不可用**：`0700.HK` 没有被识别成港股，Google News RSS 拿整串 `0700.HK 股票` 去搜，实测 0 条（换成 `00700 股票` 有 56 条）；东方财富资讯搜回 8 条里只有 1 条是腾讯本身的新闻。结果港股新闻只能靠三个要启动浏览器的 Google / Yahoo 策略，一旦这两个网站被拦就一条都拿不到。现在 `0700.HK` 与 `hk00700` 两种写法都能识别。注意单独输入 `0700` / `00700` 这类纯数字**不会**被当作港股——那更可能是 A 股代码少打了一位，我们宁可让你看到「没找到」，也不给你一份查错了股票却看不出异常的分析。
- **设置页布局塌掉**：5 行设置项的标题和说明挤在同一行、开关和按钮掉到下一行、没有分隔线、最后一行按钮被裁掉一半。原因是这批样式所在的文件从项目早期起就没被加载过。现已修好；设置面板、分析栏、选股浮层的滚动条也随之按原设计隐藏。
- **英文 / 日文界面里的中文残留**：顶部指数条的五个指数简称、公司详情里的「万」「亿」单位此前固定显示中文，现在随界面语言切换。

### ⚡ 性能 & 体验 / Performance & UX

- **后台进程每次启动更轻**：应用每次取数都会启动一个后台进程，包括每 10 秒一次的报价刷新。此前一个不起眼的引用把整套新闻抓取和三个 AI SDK 拖进了启动路径，报价刷新也要跟着加载。现在启动时加载的模块从 **38 个降到 15 个**，这部分耗时从 **46 ms 降到 6.8 ms**。
- **正式版不再夹带开发用假数据**：此前 443 行仅供开发调试的假数据会打进每个正式版，现只在开发模式加载，前端包因此减少约 **7.6 kB**。
- **自动更新遵循系统代理**：从本版起，应用内检查与下载更新会走系统代理设置，需要代理才能访问 GitHub 的用户后续更新更顺畅。
- 依赖升级至 React 19.3、最新版 Tauri 插件与 AI SDK（OpenAI / Anthropic）、Playwright 1.63。

### 📦 安装 / Installation

**macOS**（当前构建矩阵仅出 Apple Silicon，无 Intel x64 dmg）
1. 下载 `StockAI_0.17.0_aarch64.dmg`（Apple Silicon）
2. 打开 DMG，将 StockAI 拖入 Applications
3. 首次启动若提示「无法验证开发者」：系统设置 → 隐私与安全性 → 仍要打开

**Windows**
1. 下载 `StockAI_0.17.0_x64-setup.exe`，双击安装，按向导操作即可

**Linux**
1. 下载 `StockAI_0.17.0_amd64.deb`
2. `sudo dpkg -i StockAI_0.17.0_amd64.deb`

**首次配置**
打开应用 → 右上角设置 → 填入 AI 提供商（OpenAI / DeepSeek / GLM / Anthropic / Ollama）的 API Key → 保存，即可开始使用。

> 已安装 v0.15.0 及以上版本的用户会收到应用内更新提示，无需手动下载。

## StockAI v0.17.0

> Three market-behavior masters now read fund flows, Hong Kong stock news is back, the Settings layout is fixed — and you can finally attach logs when reporting a problem.

### ✨ New Features

- **Druckenmiller, Burry and Wood now weigh institutional fund flows**: fund-flow data has long been shown in the UI, yet none of the 13 masters read it. It now feeds the three whose philosophies already treat market behavior as evidence — Stanley Druckenmiller checks whether momentum is backed by real money, Michael Burry looks at who is selling and whether that signals mispricing, and Cathie Wood watches whether the market is starting to price in an innovation story. The other 10 value-oriented masters deliberately do not get it: for someone reading years of financial statements, daily money flows are noise. This also makes the consensus more trustworthy — previously all 13 read identical data and differed only in wording, so a "10/13 bullish" call was heavily overstated. Once the main-money direction flips, deep analysis no longer reuses these three masters' cached verdicts, so a conclusion drawn during inflows is never passed off as current during outflows.
- **Attach diagnostic logs in one click when something goes wrong**: Settings → General → Diagnostic logs → "Open folder", then attach the `sidecar.log` inside to your issue — it makes the cause far easier to pin down. Previously the installed app discarded almost all diagnostic output, and 90% of what did survive was the every-10-seconds quote refresh. Key clues such as data-source fallbacks and scrape failures are now recorded; logs live in the system's app log directory so updates no longer wipe them, rotate at 512 KB per file so they never grow unbounded, and have API keys and other secrets scrubbed before writing, so they are safe to paste into an issue.

### 🐛 Bug Fixes

- **Both fast news sources for Hong Kong stocks were effectively broken**: `0700.HK` was not recognized as a Hong Kong ticker, so Google News RSS searched for the literal `0700.HK 股票` and returned 0 results (`00700 股票` returns 56), while Eastmoney News returned 8 articles of which only 1 was actually about Tencent. Hong Kong news was left relying on the three browser-based Google / Yahoo strategies, and returned nothing wherever those sites are blocked. Both `0700.HK` and `hk00700` are now recognized. Note that bare numbers like `0700` / `00700` are **not** treated as Hong Kong tickers — they are more likely an A-share code missing a digit, and we would rather tell you nothing was found than hand you an analysis of the wrong stock with no visible sign of the mistake.
- **Settings layout was broken**: in 5 settings rows the title and description were squeezed onto one line, toggles and buttons dropped to the next line, dividers were missing, and the last button was half cut off. The stylesheet holding these rules had never been loaded since early in the project. It is fixed now; scrollbars in the Settings panel, analysis column and screener overlay are also hidden as originally designed.
- **Leftover Chinese in the English / Japanese UI**: the five index short names in the top index bar and the "万 / 亿" units in company details were always shown in Chinese; they now follow the interface language.

### ⚡ Performance & UX

- **Lighter background process on every launch**: the app starts a background process for every data request, including the quote refresh that runs every 10 seconds. A single innocuous-looking import had dragged the entire news-scraping stack and three AI SDKs into the startup path, so even quote refreshes paid to load them. Modules loaded at startup dropped from **38 to 15**, and that load time from **46 ms to 6.8 ms**.
- **Release builds no longer carry development mock data**: 443 lines of placeholder data meant only for development were bundled into every release build; they now load in development mode only, trimming about **7.6 kB** from the frontend bundle.
- **Auto-update respects the system proxy**: starting with this version, checking for and downloading updates goes through your system proxy settings, so users who need a proxy to reach GitHub get smoother updates from here on.
- Dependencies upgraded to React 19.3, the latest Tauri plugins and AI SDKs (OpenAI / Anthropic), and Playwright 1.63.

### 📦 Installation

**macOS** (current build matrix ships Apple Silicon only — no Intel x64 dmg)
1. Download `StockAI_0.17.0_aarch64.dmg` (Apple Silicon)
2. Open the DMG and drag StockAI into Applications
3. If macOS says "cannot verify developer": System Settings → Privacy & Security → Open Anyway

**Windows**
1. Download `StockAI_0.17.0_x64-setup.exe` and run the installer

**Linux**
1. Download `StockAI_0.17.0_amd64.deb`
2. `sudo dpkg -i StockAI_0.17.0_amd64.deb`

**First-time setup**
Open the app → Settings (top-right) → enter your AI provider API Key (OpenAI / DeepSeek / GLM / Anthropic / Ollama) → Save. Done.

> Users on v0.15.0 or later will be prompted to update inside the app — no manual download needed.
