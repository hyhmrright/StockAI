## StockAI v0.18.0

> 从一次性分析走向持续研究与复盘：新增本地研究工作台，并修正回测、选股和大师战绩的关键统计口径。

### ✨ 新特性 / New Features

- **研究工作台**：在顶部入口保存投资论点、反证和复查日期；选择历史快照，查看新闻、量化评分与大师判断发生了哪些变化。
- **事件中心**：汇总关注列表新闻、A 股定期报告公告、价格触发、待复查论点和手工日历事件。刷新材料不会自动调用模型。
- **交易账本与收益复盘**：按账户和币种记录买卖、分红、手续费、入出金与拆股，支持 CSV 导入导出，计算现金、平均成本、已实现盈亏与日末现金流假设下的 TWR。
- **组合风险与同业对比**：查看分币种持仓集中度、HHI 和收益相关性；手选 2–5 家公司比较量化评分与财务检查项。
- **财报证据资料**：本地导入 PDF/TXT，按页保存并在对话中引用；支持查询、下载 A 股定期报告，以及 SEC 10-K/10-Q 与 XBRL 适配。引用保留材料标题、日期与原文位置。
- **分析任务与费用**：大师结果逐位返回，展示接口实际报告的 token 用量；设置模型单价后可估算费用，也可终止对应分析进程。
- **备份与合并恢复**：导出研究资料、历史、手工持仓、自选与提醒，不包含模型配置和密钥；恢复时保留现有记录，重复恢复不会重复插入同一记录。

### 🐛 修复 / Bug Fixes

- **回测结果更可靠**：默认在下一交易日开盘执行收盘信号，胜率计入买入和卖出费用；净值曲线包含初始本金。可配置日期、数据范围、手续费、滑点与交易单位。
- **大师评价与模拟组合分离**：按 5/20/60 个交易日评价到期信号，可按模型版本筛选并比较基准；模拟组合按市场分别计算，不再把重叠信号收益串联复利成资金净值。
- **选股范围透明**：先核对、编辑解析条件再执行；不支持的条件明确报错。按批继续扫描，展示覆盖范围与失败数，并对已扫描结果保持全局排序。
- **分析保存可重试**：独立分析 ID 和数据库唯一约束避免重复落账；写入失败会提示重试。切换股票立即隐藏旧标的数据，K 线保留来源与实际复权信息。

### ⚡ 性能 & 体验 / Performance & UX

- 研究工作台支持简体中文、English 和日本語；PDF 解析按需加载，材料无需上传到额外服务即可本地提取。
- 本版包含已合入主分支的桌面插件与 AI SDK 更新，前端与 Rust 依赖配套升级。
- **使用边界**：扫描图片型 PDF 需要先 OCR；SEC 在部分网络可能返回 HTTP 403，可改用本地资料导入。旧手工持仓与交易账本独立管理。TWR 需要完整流水；备份恢复为可重试合并，不是跨数据库与配置存储的原子事务。费用估算以自行配置的单价为准，实际收费以供应商账单为准。

### 📦 安装 / Installation

**macOS**（Apple Silicon，无 Intel x64 DMG）
1. 下载 `StockAI_0.18.0_aarch64.dmg`。
2. 打开 DMG，将 StockAI 拖入 Applications。
3. 首次启动若提示「无法验证开发者」：系统设置 → 隐私与安全性 → 仍要打开。

## StockAI v0.18.0

> Move from one-off analysis to ongoing research and review with a local research workspace and corrected backtest, screening and master-performance calculations.

### ✨ New Features

- **Research workspace**: save investment theses, counter-evidence and review dates from the top toolbar. Compare historical snapshots to see changes in news, quant scores and master judgments.
- **Event inbox**: collect watchlist news, A-share periodic filings, price triggers, thesis reviews and manual calendar events. Refreshing source material does not automatically call a model.
- **Transaction ledger and performance**: record buys, sells, dividends, fees, deposits, withdrawals and splits by account and currency. Import/export CSV, and calculate cash, average cost, realized P/L and TWR under an end-of-day cashflow assumption.
- **Portfolio risk and peer comparisons**: inspect concentration, HHI and return correlations by currency; choose 2–5 companies to compare quant scores and financial checks.
- **Report evidence**: import PDF/TXT locally, preserve pages and cite them in chat. Discover and download A-share periodic reports, with adapters for SEC 10-K/10-Q and XBRL. Citations retain document titles, dates and source locations.
- **Analysis tasks and costs**: receive master results incrementally, inspect API-reported token usage, estimate costs using your configured rates and terminate the corresponding analysis process.
- **Backup and merge restore**: export research, history, manual holdings, watchlists and alerts without model settings or keys. Restore preserves existing records and repeated restores do not duplicate the same records.

### 🐛 Bug Fixes

- **More reliable backtests**: close-derived signals fill at the next trading session's open by default. Win classification includes both entry and exit fees; equity curves include initial capital. Configure dates, history range, fees, slippage and lot sizes.
- **Separate master evaluation and simulated portfolios**: evaluate matured signals over 5/20/60 trading sessions, filter model versions and compare benchmarks. Simulations are split by market, rather than compounding overlapping signal returns into portfolio NAV.
- **Transparent screening coverage**: confirm and edit parsed conditions before execution. Unsupported conditions produce an error. Continue in batches, inspect coverage and failures, and retain a globally sorted ranking across scanned results.
- **Retryable analysis persistence**: stable analysis IDs and database uniqueness prevent duplicate records. Failed writes offer retry. Switching symbols immediately hides stale data, and charts retain source and actual price-adjustment metadata.

### ⚡ Performance & UX

- The workspace supports Simplified Chinese, English and Japanese. PDF parsing loads on demand and extracts text locally without uploading documents to another service.
- Includes desktop-plugin and AI SDK updates already merged into main, with coordinated frontend and Rust dependencies.
- **Limitations**: scanned image PDFs require OCR first. SEC may return HTTP 403 on some networks; local document import remains available. Legacy manual holdings and transaction accounts are independent. TWR requires complete transaction history. Restore is a retryable merge, not an atomic transaction across the database and settings store. Cost estimates use your configured prices; provider invoices determine actual charges.

### 📦 Installation

**macOS** (Apple Silicon; no Intel x64 DMG)
1. Download `StockAI_0.18.0_aarch64.dmg`.
2. Open the DMG and drag StockAI into Applications.
3. If macOS says "cannot verify developer": System Settings → Privacy & Security → Open Anyway.

**Windows**
1. Download `StockAI_0.18.0_x64-setup.exe` and follow the installer.

**Linux**
1. Download `StockAI_0.18.0_amd64.deb`.
2. Run `sudo dpkg -i StockAI_0.18.0_amd64.deb`.

**First-time setup**
Open the app → Settings (top-right) → enter your AI provider API key (or use local Ollama) → Save. Users on v0.15.0 or later can upgrade through the in-app updater.
