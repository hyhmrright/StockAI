## StockAI v0.16.0

> 从「单股分析工具」长成「完整看盘台」：新增真实持仓管理、大盘指数条、板块涨幅榜、龙虎榜与公司 F10 资料，并修好了让美股基本面整片为空、以及分析偶尔卡住不返回的两个硬伤。

### ✨ 新特性 / New Features

- **我的持仓** — 记下你真正买了什么（份额 + 成本价），实时市值、浮动盈亏、当日盈亏、仓位占比一屏看全；加仓时按份额加权自动合并成本价，不用自己按计算器。A 股与美股**分币种汇总、绝不相加**——本应用没有汇率数据源，硬把人民币和美元加起来只会得到一个没有意义的数字。取不到报价的标的会被排除出汇总并显式点名，而不是拿 0 顶替让你以为亏光了。
- **大盘指数条** — 顶部常驻上证 / 深证 / 创业板 / 标普 500 / 纳斯达克 / 道琼斯，开着应用就知道今天大盘什么脸色。
- **板块涨幅榜** — 点指数条展开行业与概念两张榜，含主力净流入、板块内涨跌家数与领涨股。看到哪个板块在动，点领涨股直接切过去分析。
- **龙虎榜** — 最新交易日的净买入 / 净卖出前十，附上榜原因与成交额占比。同一只股票同日触发多个上榜标准时**各条分别列出**——不同统计窗口的净额本就不同，合并会得到一个交易所从未披露过的数字。
- **公司资料（F10）** — 个股页新增折叠区：公司概况、最新报告期主营构成（按产品 / 行业 / 地区，含毛利率）、股东户数与十大流通股东、所属板块。仅 A 股，默认收起、展开才拉取。
- **关注列表直接显示涨跌** — 现价与涨跌幅显示在列表里，按 A 股红涨 / 美股绿涨的习惯着色。
- **首启引导** — 第一次打开不再甩你一屏报错，而是直接指路「去设置里填 API Key」。

### 🐛 修复 / Bug Fixes

- **美股基本面整片为空**：Yahoo 的数据接口新增了 cookie + crumb 校验，没握手一律返回 401，导致美股的市盈率、ROE 等字段全是空白。现已补上握手流程，美股基本面恢复。
- **分析偶尔卡住不返回**：三条路径各修一处——抓取策略全部走空时会无限期挂起、正文提取没纳入超时预算、以及卡死的 Chromium 进程让整个调用永远等不到结果。现在写完结果即退出，Rust 侧另加宽限回收兜底。
- **切换语言只有设置页跟着变**：设置状态此前每个调用方各持一份，改完语言只有当前这个组件重渲染，退出去主界面还是旧语言。现已收敛为全应用单例。
- **北交所 920 号段被当成美股**：代码识别只认 6/0/3/4/8 开头，2024 年启用的 920 段落进了美股链路，K 线与报价一律取不到——选股选中后点开必然空白。
- **回测胜率虚高**：此前判定盈亏只比买卖两端价格、没算手续费，凡毛涨幅低于一买一卖两道费（默认约 0.2%）的单子实际是亏的，却被记成盈利单。现按扣费后真正落袋的金额判定。同时修好了净值曲线终点与总收益率对不上的问题。
- **副图指标切到 BOLL 时整页白屏**。
- **搜索结果错位**：快速连续输入时，后发的请求可能被先到的旧响应覆盖；请求失败时还会保留上一次的结果，看起来像「搜到了别的股票」。
- **持仓连点加仓算错成本价**：读—改—写两步之间存在竞态窗口，连续两次加仓会各自基于同一份旧值计算、后写覆盖前写。现改为单条 SQL 原子合并。
- **大师命中率被半份记录带偏**：13 位大师的判断此前逐条写库，中途失败会留下不完整的一批，统计命中率时按残缺样本算。
- **英文 / 日文界面出现中文报错**：服务端错误此前把中文技术信息直接上屏；现全链路带错误码，由界面按当前语言渲染。

### ⚡ 性能 & 体验 / Performance & UX

- **龙虎榜与板块榜重复打开不再重走网络**：实测冷启动 3974 ms → 命中缓存 82 ms。缓存有效期按数据本身的变化频率定——龙虎榜 30 分钟（日频数据，但发布时刻不固定），板块榜 60 秒（盘中实时变动）。
- **价格告警不再通宵轮询**：此前无视交易时段，A 股夜里两点照样每 10 秒请求一次；且逐只标的分别取价，5 条告警就是每 10 秒起 5 个后台进程。现改为仅交易时段、单次批量取价。
- **报价轮询收敛为全应用单例**：关注列表、持仓、指数条共用一个定时器和一次批量请求，不再按消费方个数成倍放大后台进程。
- **大师虚拟组合改批量取价**，不再按分析过的标的数逐只起进程。
- 依赖全量升级：lightweight-charts v5、Vite 8、TypeScript 7。

### 📦 安装 / Installation

**macOS**（当前构建矩阵仅出 Apple Silicon，无 Intel x64 dmg）
1. 下载 `StockAI_0.16.0_aarch64.dmg`（Apple Silicon）
2. 打开 DMG，将 StockAI 拖入 Applications
3. 首次启动若提示「无法验证开发者」：系统设置 → 隐私与安全性 → 仍要打开

**Windows**
1. 下载 `StockAI_0.16.0_x64-setup.exe`，双击安装，按向导操作即可

**Linux**
1. 下载 `StockAI_0.16.0_amd64.deb`
2. `sudo dpkg -i StockAI_0.16.0_amd64.deb`

**首次配置**
打开应用 → 右上角设置 → 填入 AI 提供商（OpenAI / DeepSeek / GLM / Anthropic / Ollama）的 API Key → 保存，即可开始使用。

## StockAI v0.16.0

> Grows from a single-stock analyzer into a full trading desk: real portfolio tracking, a market index bar, sector and top-trader leaderboards, and company profiles — plus fixes for two hard failures: US fundamentals coming back empty, and analysis occasionally hanging forever.

### ✨ New Features

- **My Holdings** — Track what you actually own (shares + cost basis) and see market value, unrealized P&L, daily P&L, and position weight at a glance. Adding to a position merges the cost basis by share-weighted average automatically. A-shares and US stocks are **summarized per currency and never added together** — this app has no FX data source, so combining CNY and USD would produce a meaningless number. Holdings with no available quote are excluded from the totals and named explicitly, rather than counted as zero and making your portfolio look wiped out.
- **Market index bar** — Shanghai / Shenzhen / ChiNext / S&P 500 / Nasdaq / Dow, always visible at the top.
- **Sector leaderboard** — Click the index bar to expand industry and concept rankings, with net institutional inflow, advancing/declining counts, and each sector's leading stock. Click a leader to jump straight into analyzing it.
- **Top-trader leaderboard (龙虎榜)** — The latest session's top ten net buys and net sells, with the qualifying reason and share of turnover. When one stock triggers several criteria on the same day, **each entry is listed separately** — different statistical windows genuinely have different net amounts, and merging them would invent a figure the exchange never published.
- **Company profile (F10)** — A new collapsible section on the stock page: company overview, latest-period revenue breakdown (by product / industry / region, with gross margin), shareholder counts and top ten circulating holders, and sector membership. A-shares only; collapsed by default and fetched only when opened.
- **Live change in the watchlist** — Current price and percentage change shown right in the list, colored by local convention (red-up for A-shares, green-up for US).
- **First-run onboarding** — Opening the app for the first time no longer throws a screen of errors at you; it points you to Settings to add an API key.

### 🐛 Bug Fixes

- **US fundamentals came back empty**: Yahoo's data endpoint added a cookie + crumb check, returning 401 without the handshake, which blanked P/E, ROE, and every other US fundamental field. The handshake is now implemented and US fundamentals work again.
- **Analysis occasionally hung forever**: fixed in three places — the scrape strategy chain could hang indefinitely when every strategy came up empty, article extraction wasn't covered by the timeout budget, and a stuck Chromium process could leave the whole call waiting for a result that never came. The backend now exits as soon as it has written its result, with a grace-period reap on the Rust side as a backstop.
- **Changing the language only updated the settings page**: settings state was held separately by each consumer, so switching languages re-rendered only the current component while the main UI stayed in the old language. It's now a single app-wide instance.
- **Beijing Exchange 920-prefix codes were treated as US tickers**: symbol detection only recognized 6/0/3/4/8 prefixes, so the 920 range (introduced in 2024) fell through to the US path and never returned candles or quotes — screener results were guaranteed to open blank.
- **Backtest win rate was inflated**: profit/loss was judged by comparing entry and exit prices without commission, so any trade whose gross gain fell below the two-way fee (about 0.2% by default) was actually a loss but got counted as a win. It's now judged on what you'd actually keep after fees. The equity curve's endpoint no longer disagrees with the reported total return either.
- **Blank screen when switching the sub-chart indicator to BOLL**.
- **Search results landed on the wrong stock**: with fast consecutive typing, a later request could be overwritten by an earlier response arriving late; failed requests also kept the previous results on screen, which looked like the wrong stock had been found.
- **Rapid repeat buys computed the wrong cost basis**: the read-modify-write sequence had a race window, so two quick additions each calculated from the same stale value and the later write clobbered the earlier one. It's now a single atomic SQL merge.
- **Master hit rates were skewed by partial records**: the 13 masters' verdicts were written one row at a time, so a mid-way failure left an incomplete batch that hit-rate statistics then treated as a full sample.
- **Chinese error text appeared in the English and Japanese UI**: server-side errors used to surface raw Chinese technical messages; errors now carry a code end-to-end and are rendered in the active language.

### ⚡ Performance & UX

- **Reopening the top-trader and sector leaderboards no longer re-fetches**: measured 3,974 ms cold → 82 ms cached. TTLs follow how fast the data actually changes — 30 minutes for the top-trader board (daily data, but published at an unpredictable hour) and 60 seconds for sectors (moves throughout the session).
- **Price alerts no longer poll all night**: alert monitoring used to ignore market hours, hitting the network every 10 seconds at 2 a.m.; it also priced each symbol separately, so five alerts meant five background processes every 10 seconds. Now it runs only during market hours, in a single batched request.
- **Quote polling is now a single app-wide instance**: the watchlist, holdings, and index bar share one timer and one batched request instead of multiplying background processes per consumer.
- **Master virtual portfolios fetch prices in batch** rather than spawning one process per analyzed symbol.
- Dependencies fully upgraded: lightweight-charts v5, Vite 8, TypeScript 7.

### 📦 Installation

**macOS** (current build matrix ships Apple Silicon only — no Intel x64 dmg)
1. Download `StockAI_0.16.0_aarch64.dmg` (Apple Silicon)
2. Open the DMG and drag StockAI into Applications
3. If macOS says "cannot verify developer": System Settings → Privacy & Security → Open Anyway

**Windows**
1. Download `StockAI_0.16.0_x64-setup.exe` and run the installer

**Linux**
1. Download `StockAI_0.16.0_amd64.deb`
2. `sudo dpkg -i StockAI_0.16.0_amd64.deb`

**First-time setup**
Open the app → Settings (top-right) → enter your AI provider API Key (OpenAI / DeepSeek / GLM / Anthropic / Ollama) → Save. Done.
