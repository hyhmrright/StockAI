## StockAI v0.16.1

> 可靠性补丁：Yahoo 访问不了的地区终于能看美股，单个数据源整机故障也不再让整片面板空白。

### 🐛 修复 / Bug Fixes

- **Yahoo 不可达时美股不再一片空白**：此前美股 K 线与报价只有 Yahoo 一条路，Yahoo 被墙或抽风时价格、图表全部取不到。现在 K 线补上新浪兜底，报价改为腾讯 → 新浪 → Yahoo 依次尝试。顺带修掉一个隐性卡顿——报价每 10 秒轮询一次，把国内可达的源排在前面之前，Yahoo 不可达时每一轮都要先吃满 8 秒超时才轮到下一个。
- **单个数据源整机故障不再拖垮整块面板**：8 月 9 日东方财富 `push2*` 接口家族整体故障（连接重置 / 502），暴露出多条没有备份的取数链路。现已逐条补上：A 股 K 线补到三源（腾讯 → 东财 → 新浪）、板块涨幅榜 / 资金流 / 全市场基本面快照各补新浪备源、美股基本面补东财备源。仅剩龙虎榜、公司 F10、财报历史、A 股基本面四项确无可用的备用接口，已在架构文档中记明。
- **备用数据源缺的字段显示「—」，不拿 0 顶替**：新浪的板块榜没有主力资金流与涨跌家数，资金流数据也没有日期。显示成 `0` 会被读成「今天没有资金进出」，而那是一句我们并不知道的断言。
- **发版时 `Cargo.lock` 版本号漏改**：版本号同步脚本此前只改三个文件，Cargo.lock 靠手工补刀，漏掉就留下一棵版本半同步的源码树。
- **Linux 构建每月一炸**：CI 固定的 linuxdeploy 校验哈希对着上游的滚动 tag，上游一更新构建就失配挂掉。现改从自建资产获取，哈希不再漂移。

### ⚡ 质量 / Quality

- 为并发调度、AI 返回值解析、HTTP 统一出口、缓存淘汰、多语言数字分档五处核心工具函数补齐测试（新增 41 条），并修掉大额负数格式化不分档的潜在缺陷。

### 📦 安装 / Installation

**macOS**（当前构建矩阵仅出 Apple Silicon，无 Intel x64 dmg）
1. 下载 `StockAI_0.16.1_aarch64.dmg`（Apple Silicon）
2. 打开 DMG，将 StockAI 拖入 Applications
3. 首次启动若提示「无法验证开发者」：系统设置 → 隐私与安全性 → 仍要打开

**Windows**
1. 下载 `StockAI_0.16.1_x64-setup.exe`，双击安装，按向导操作即可

**Linux**
1. 下载 `StockAI_0.16.1_amd64.deb`
2. `sudo dpkg -i StockAI_0.16.1_amd64.deb`

**首次配置**
打开应用 → 右上角设置 → 填入 AI 提供商（OpenAI / DeepSeek / GLM / Anthropic / Ollama）的 API Key → 保存，即可开始使用。

> 已安装 v0.15.0 及以上版本的用户会收到应用内更新提示，无需手动下载。

## StockAI v0.16.1

> A reliability patch: US market data now works where Yahoo Finance is unreachable, and a single upstream outage no longer blanks out entire panels.

### 🐛 Bug Fixes

- **US stocks no longer go blank when Yahoo is unreachable**: US charts and quotes previously had exactly one source — Yahoo Finance — so prices and charts disappeared entirely wherever it is blocked or flaky. Charts now fall back to Sina, and quotes try Tencent → Sina → Yahoo in order. This also removes a hidden stall: quotes poll every 10 seconds, and before the reordering, every single round had to burn the full 8-second timeout on an unreachable Yahoo before trying anything else.
- **A single upstream outage no longer takes a whole panel down**: On August 9 the entire Eastmoney `push2*` API family failed (connection resets / 502s), exposing several fetch paths with no backup. Each has now been given one: A-share charts have three sources (Tencent → Eastmoney → Sina), while sector rankings, fund flow, and the full-market fundamentals snapshot each gained a Sina backup, and US fundamentals gained an Eastmoney backup. Only four capabilities remain single-sourced — the dragon-tiger board, company profiles (F10), financial history, and A-share fundamentals — because no usable alternative API exists; this is documented in the architecture notes.
- **Fields missing from a backup source display "—" rather than 0**: Sina's sector rankings carry no institutional fund flow or advance/decline counts, and its fund flow data has no date. Rendering those as `0` would read as "no money moved today" — a claim we have no basis to make.
- **`Cargo.lock` version was left behind on release**: The version-sync script previously updated only three files, leaving Cargo.lock to a manual follow-up that, when forgotten, left a half-synced source tree.
- **Linux builds broke once a month**: CI pinned a linuxdeploy checksum against an upstream rolling tag, so every upstream refresh broke the build with a hash mismatch. It now pulls from a self-hosted asset, so the hash no longer drifts.

### ⚡ Quality

- Added test coverage (41 new tests) for five core utilities — concurrency scheduling, AI response parsing, the unified HTTP entry point, cache eviction, and locale-aware number formatting — and fixed a latent bug where large negative numbers were not bucketed into compact units.

### 📦 Installation

**macOS** (current build matrix ships Apple Silicon only — no Intel x64 dmg)
1. Download `StockAI_0.16.1_aarch64.dmg` (Apple Silicon)
2. Open the DMG and drag StockAI into Applications
3. If macOS says "cannot verify developer": System Settings → Privacy & Security → Open Anyway

**Windows**
1. Download `StockAI_0.16.1_x64-setup.exe` and run the installer

**Linux**
1. Download `StockAI_0.16.1_amd64.deb`
2. `sudo dpkg -i StockAI_0.16.1_amd64.deb`

**First-time setup**
Open the app → Settings (top-right) → enter your AI provider API Key (OpenAI / DeepSeek / GLM / Anthropic / Ollama) → Save. Done.

> If you are on v0.15.0 or later, the app will offer this update in-place — no manual download needed.
