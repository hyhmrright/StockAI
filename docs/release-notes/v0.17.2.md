## StockAI v0.17.2

> 依赖维护版本：同步更新桌面系统插件、AI 接口与新闻抓取组件，现有使用方式保持不变。

### ⚡ 性能 & 体验 / Performance & UX

- **桌面系统组件同步更新**：通知、外部程序调用、链接打开与自动更新插件升级，Rust 与前端版本保持配套，解决分开升级时安装包无法构建的问题。
- **AI 与新闻抓取组件更新**：OpenAI SDK 升至 7.33.0、Anthropic SDK 升至 0.133.0、Playwright 升至 1.64.1。继续使用现有 AI 提供商和 API Key 即可，无需重新配置。
- **维护范围**：本版以依赖更新为主，没有新增应用功能；macOS、Windows、Linux 的测试与桌面构建，以及真实浏览器中的 K 线冒烟检查均已通过。

### 📦 安装 / Installation

**macOS**（当前构建矩阵仅出 Apple Silicon，无 Intel x64 dmg）
1. 下载 `StockAI_0.17.2_aarch64.dmg`（Apple Silicon）
2. 打开 DMG，将 StockAI 拖入 Applications
3. 首次启动若提示「无法验证开发者」：系统设置 → 隐私与安全性 → 仍要打开

**Windows**
1. 下载 `StockAI_0.17.2_x64-setup.exe`，双击安装，按向导操作即可

**Linux**
1. 下载 `StockAI_0.17.2_amd64.deb`
2. `sudo dpkg -i StockAI_0.17.2_amd64.deb`

**首次配置**
打开应用 → 右上角设置 → 填入 AI 提供商（OpenAI / DeepSeek / GLM / Anthropic / Ollama）的 API Key → 保存，即可开始使用。

> 已安装 v0.15.0 及以上版本的用户会收到应用内更新提示，无需手动下载。

## StockAI v0.17.2

> A maintenance release updating desktop plugins, AI integrations and news browsing components, with the same app workflow.

### ⚡ Performance & UX

- **Coordinated desktop component updates**: updated notifications, external process execution, link opening and auto-update plugins. Rust and frontend versions stay aligned, resolving the package build failures caused by upgrading them separately.
- **Updated AI and news browsing components**: OpenAI SDK 7.33.0, Anthropic SDK 0.133.0 and Playwright 1.64.1. Keep using your existing AI provider and API key; no reconfiguration is required.
- **Maintenance scope**: this release focuses on dependency updates and adds no new app features. Tests and desktop builds on macOS, Windows and Linux, plus the candlestick smoke test in a real browser, have passed.

### 📦 Installation

**macOS** (current build matrix ships Apple Silicon only — no Intel x64 dmg)
1. Download `StockAI_0.17.2_aarch64.dmg` (Apple Silicon)
2. Open the DMG and drag StockAI into Applications
3. If macOS says "cannot verify developer": System Settings → Privacy & Security → Open Anyway

**Windows**
1. Download `StockAI_0.17.2_x64-setup.exe` and run the installer

**Linux**
1. Download `StockAI_0.17.2_amd64.deb`
2. `sudo dpkg -i StockAI_0.17.2_amd64.deb`

**First-time setup**
Open the app → Settings (top-right) → enter your AI provider API Key (OpenAI / DeepSeek / GLM / Anthropic / Ollama) → Save. Done.

> Users on v0.15.0 or later will be prompted to update inside the app — no manual download needed.
